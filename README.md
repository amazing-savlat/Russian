# Литературная викторина

Командная игра в стиле Jeopardy для урока литературы: три команды, четыре категории, четыре уровня стоимости, вопросы «Кот в мешке».

## Как добавить вопросы

Откройте `src/data/questions.ts` и заполните массив `questions` (пример и описание полей — в комментарии в том же файле). После этого пересоберите приложение (`npm run build`).

- `questionType` — колонка: `analysis` (Анализ), `details` (Детали), `events` (События), `characters` (Персонажи).
- `level` — строка: `easy`, `middle`, `intermediate`, `hard`.
- `answerPoints` — сколько баллов даёт вопрос.
- `isCatInBag: true` — «Кот в мешке» (+50 баллов за правильный ответ).

Если в файле есть ошибки (повторяющийся `id`, неизвестная категория, пустой ответ и т. п.), стартовый экран покажет их список.

## Прочие настройки

- Названия команд по умолчанию — `src/data/teams.ts` (их также можно изменить на стартовом экране).
- Название викторины, подзаголовок, бонус «Кота в мешке», подписи категорий — `src/data/config.ts`.

## Запуск

```bash
npm install        # один раз
npm run build      # собирает dist/index.html
```

`dist/index.html` — один самодостаточный файл: его можно скопировать на флешку и открыть в любом браузере без интернета и без сервера. Для полноэкранного режима нажмите F11.

Для разработки: `npm run dev`. Тесты игровой логики: `npm test`.

## Структура

```
src/data/        — вопросы, команды, настройки (данные)
src/game/        — игровая логика без React (logic.ts) и её тесты
src/components/  — экраны: старт, поле, вопрос, табло, результаты
```
